### Paso 3: Guardar y Salir
Una vez que hayas pegado el texto dentro de `nano`, sigue estos tres pasos con tu teclado para guardarlo:
1. Presiona **`Ctrl + O`** (para guardar).
2. Presiona la tecla **`Enter`** (para confirmar el nombre del archivo).
3. Presiona **`Ctrl + X`** (para cerrar el editor y volver a tu terminal normal).
